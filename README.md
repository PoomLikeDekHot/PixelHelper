# PixelHelper

Helper script for Pixel Lineage (Roblox). Run this in your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/PoomLikeDekHot/PixelHelper/main/PixelHelper.lua"))()
```

It always loads the latest version, restarts itself after teleports, and downloads the bubble picture on first run.
Settings are saved per Roblox account in your executor's workspace folder (`PixelHelper_Settings_<UserId>.json`).
